# Fonts

Both typefaces are self-hosted so the app makes no request to a font service.

| File | Typeface | Licence | Source |
|---|---|---|---|
| `hanken-grotesk-latin-wght.woff2` | Hanken Grotesk (variable weight, Latin subset) | SIL Open Font License 1.1 | Fontsource, `hanken-grotesk` |
| `doto-latin-wght.woff2` | Doto (variable weight, Latin subset) | SIL Open Font License 1.1 | Fontsource, `doto` |

Hanken Grotesk sets all text. Doto sets the headline figures only (see `DESIGN.md`).
