# Fonts

The typeface is self-hosted so the app makes no request to a font service.

| File | Typeface | Licence | Source |
|---|---|---|---|
| `public-sans-latin-wght.woff2` | Public Sans (variable weight, Latin subset) | SIL Open Font License 1.1 | Google Fonts, `Public Sans` v21 |

Public Sans sets all text and numbers (see `DESIGN.md`).
